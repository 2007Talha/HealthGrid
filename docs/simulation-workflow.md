# Swasthya Records — Simulation Workflow & State Transitions

## 1. Overview

Swasthya Records implements a safe, reversible simulation lifecycle designed for public health decision-makers. Administrative stakeholders can inspect recommendations, simulate their impact across the hospital network, and revert at any time with complete audit integrity.

---

## 2. State Transition Lifecycle

```
       +-----------------------+
       |   SHORTAGE DETECTED   |
       +-----------+-----------+
                   |
                   v
       +-----------------------+
       |   PROPOSED (SOLVER)   | <----+
       +-----------+-----------+      |
                   |                  |
    Execute Transfer Simulation       | One-Click
                   |                  | Reset
                   v                  |
       +-----------------------+      |
       |   SIMULATED (ACTIVE)  | -----+
       +-----------+-----------+
                   |
     Optional Human Approval
                   |
                   v
       +-----------------------+
       | DISPATCHED (APPROVED) |
       +-----------------------+
```

### State Definitions
1. **PROPOSED**: An optimal multi-source transfer plan generated by Google OR-Tools CBC solver. No inventory changes are committed.
2. **SIMULATED**: Transfer quantities are applied to the active in-memory operational state buffer. Destination stock increases; source stocks decrease; DOSA and risk levels are recalculated.
3. **RESET**: The operational state is reverted to the pre-simulation baseline.
4. **DISPATCHED**: Official human sign-off approving logistics movement.

---

## 3. Risk Recalculation Engine

Upon executing a simulation:
- **Before State**: Destination DOSA (e.g. $1.8\text{ days}$), Risk Level: `CRITICAL` or `HIGH`.
- **Transfer Applied**: Stock adjusted by $+\sum x_{sd}$ at destination and $-x_{sd}$ at each donor source.
- **After State**: Destination DOSA recalculated as $(I_d + \sum x_{sd}) / \bar{D}_d$ (e.g. $8.5\text{ days}$), Risk Level transitioned to `LOW`.
- **Donor Verification**: Donor DOSA verified to remain $\ge 10.0\text{ days}$ and stock $\ge \text{SafetyStock}_s$.

---

## 4. API Endpoints

- `GET /api/v1/redistribution/shortages`: Lists all current PHC medicine deficits.
- `GET /api/v1/redistribution/sources`: Discovers and ranks candidate donor facilities.
- `GET /api/v1/redistribution/routes`: Returns routing distance and transit matrix.
- `POST /api/v1/redistribution/recommend`: Executes Google OR-Tools optimization.
- `POST /api/v1/redistribution/simulate`: Executes simulated transfer and recalculates risks.
- `POST /api/v1/redistribution/reset`: Reverts simulation changes.
